ขั้นตอนการให้บริการ Dashboard

เราทำงานร่วมกันอย่างไรในการสร้าง Dashboard ของคุณ

ฝ่ายข้อมูลและทรัพยากรสารสนเทศให้บริการข้อมูลจากระบบ HIS และคลังข้อมูลกลาง เพื่อสนับสนุนการตัดสินใจ การบริหารจัดการ และการวิจัยอย่างมีมาตรฐาน โปร่งใส และปลอดภัย

ขั้นตอนการให้บริการตั้งแต่ต้นจนจบ (สำหรับผู้ขอใช้บริการ)

  1. 1

    รับคำขอ (Email Screening)

    ผู้ขอใช้บริการส่งรายละเอียดเบื้องต้นจากอีเมลหน่วยงาน (@chulahospital.org หรือ @chula.md) มาที่ napalai.poo@dd-kcmh.com

  2. 2

    ตอบรับเบื้องต้น (ภายใน 3 วันทำการ)

    ทีม BI ตรวจสอบความเป็นไปได้และแจ้งขั้นตอนถัดไปหรือเอกสารที่ต้องใช้

  3. 3

    ประชุมชี้แจงความต้องการ (Discovery & Requirement Clarification)

    ประชุมร่วมกันเพื่อกำหนดวัตถุประสงค์ทางธุรกิจ นิยาม KPI กลุ่มเป้าหมาย ความถี่รายงาน และขอบเขตข้อมูล

  4. 4

    ประเมินโครงการและจัดลำดับคิว

    ทีมงานประเมินขอบเขตตามเกณฑ์บริการและจัดคิวตามผลกระทบต่อองค์กร ความพร้อมของข้อมูล และความถี่การรายงาน

  5. 5

    Data Mapping & Model Preparation

    ระบุแหล่งข้อมูล กำหนด logic การแปลงข้อมูล และเตรียมชุดข้อมูลที่ผ่านการกำกับดูแล (ไม่ใช่ real-time)

  6. 6

    สร้าง Dashboard (ฉบับร่าง)

    สร้างฉบับร่างพร้อมกราฟ ตัวกรอง มุมมอง drill-down และ layout ที่สอดคล้องกับ workflow การตัดสินใจ

  7. 7

    ตรวจสอบ/ทดสอบ (Validation / UAT)

    ผู้ขอใช้บริการและ Data Champion ตรวจสอบตัวเลขและ logic เทียบกับข้อมูลอ้างอิงก่อนอนุมัติ

  8. 8

    เผยแพร่ขึ้น Tableau Server

    Dashboard ที่ผ่านการอนุมัติจะถูกเผยแพร่พร้อมกำหนดสิทธิ์การเข้าถึงตามบทบาท

  9. 9

    อบรมและปรับปรุงอย่างต่อเนื่อง

    อบรมทีมงาน ติดตามการใช้งาน รับฟัง feedback และพัฒนาอย่างต่อเนื่อง

สิ่งที่ต้องการจากผู้ขอใช้บริการ

  • ปัญหาการดำเนินงานหรือคำถามเชิงบริหารที่ชัดเจน
  • ตัวอย่างรายงาน/ไฟล์ที่ใช้งานจริง (ถ้ามี)
  • Data Champion ที่ได้รับมอบหมายจากหน่วยงาน
  • มีส่วนร่วมในการทดสอบ UAT และยืนยัน KPI
  • ตอบข้อสงสัยเกี่ยวกับ logic ทางธุรกิจอย่างรวดเร็วเมื่อมีประเด็น

สิ่งที่ผู้ขอใช้บริการจะได้รับจากเรา

  • ขั้นตอน BI ที่โปร่งใสและเป็นระบบตั้งแต่รับคำขอจนถึงเผยแพร่
  • ช่วยแปลง KPI ให้เป็น logic ข้อมูลที่ชัดเจน
  • แจ้งข้อจำกัดหรือช่องว่างของข้อมูลอย่างตรงไปตรงมา
  • มีฉบับร่างให้ตรวจสอบก่อนขึ้น production
  • อบรม/แนะนำการใช้งานก่อนเปิดใช้งานจริง

เกณฑ์การให้บริการ (สรุป)

ลักษณะโครงการที่เข้าเกณฑ์

  • สอดคล้องกับเป้าหมายการบริหารหรือปรับปรุงการดำเนินงาน
  • ไม่ใช่การวิเคราะห์เฉพาะกิจส่วนบุคคล
  • ใช้ข้อมูลที่อัปเดตเป็นรอบ (รายเดือน/รายไตรมาส/รายครึ่งปี/รายปี)
  • ไม่ต้องการข้อมูลแบบ real-time

หลักการจัดลำดับความสำคัญ

  • ระดับผลกระทบ: ทั้งโรงพยาบาล > ระดับฝ่าย/แผนก > ระดับทีม
  • ความพร้อมของข้อมูลและความชัดเจนของความต้องการ
  • มี Data Champion ของหน่วยงาน
  • ความถี่ในการนำไปใช้ตัดสินใจเชิงปฏิบัติการ

ความสามารถในการให้บริการ BI มีจำกัด การจัดคิวจะเป็นไปตามเกณฑ์ที่โปร่งใสเพื่อให้เกิดประโยชน์สูงสุดต่อโรงพยาบาล

ทีมของคุณนำเสนอเป้าหมายเชิงปฏิบัติการและ KPI
ทีม BI ของเราจะแปลงเป้าหมายเหล่านั้นเป็น logic ข้อมูลที่ผ่านการกำกับดูแล
เราออกแบบ Dashboard และตรวจสอบผลลัพธ์ร่วมกัน
