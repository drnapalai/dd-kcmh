Business Intelligence

บริการสนับสนุนการพัฒนา Dashboard สำหรับการบริหารจัดการหน่วยงาน ด้วยข้อมูลจากระบบโรงพยาบาลและคลังข้อมูลกลาง ภายใต้หลัก Data Governance

บริการข้อมูลสำหรับการจัดทำ Dashboard เพื่อการบริหารจัดการ

เราช่วยหน่วยงานแปลง “คำถามเชิงบริหาร” และ KPI ให้เป็น Dashboard ที่ใช้งานได้จริง ตรวจสอบได้ และนำไปใช้ติดตามผลการดำเนินงานอย่างต่อเนื่อง

กรอกแบบฟอร์มคำขอ BI ดูขั้นตอนการทำงานร่วมกัน
เป้าหมาย Dashboard เพื่อการบริหารจัดการและการปรับปรุงการดำเนินงาน ไม่ใช่รายงานเฉพาะกิจรายครั้ง
ข้อมูล ใช้ข้อมูลจาก HIS และคลังข้อมูลกลาง โดยมีรอบการอัปเดตตามความเหมาะสม เช่น รายเดือนหรือรายไตรมาส
การทำงานร่วมกัน หน่วยงานต้องมี Data Champion เพื่อช่วยยืนยัน KPI, business logic และผลการทดสอบ UAT

เราทำงานร่วมกันอย่างไรในการสร้าง Dashboard ให้หน่วยงานของท่าน

การพัฒนา Dashboard ที่ดีต้องอาศัยทั้งความเข้าใจบริบทหน้างานจากหน่วยงาน และความเชี่ยวชาญด้านข้อมูลจากทีม BI

สิ่งที่ต้องการจากผู้ขอใช้บริการ

  • ปัญหาการดำเนินงานหรือคำถามเชิงบริหารที่ชัดเจน
  • ตัวอย่างรายงาน/ไฟล์ที่ใช้งานจริง หากมี
  • Data Champion ที่ได้รับมอบหมายจากหน่วยงาน
  • การมีส่วนร่วมในการทดสอบ UAT และยืนยัน KPI
  • การตอบข้อสงสัยเกี่ยวกับ logic ทางธุรกิจเมื่อมีประเด็น

สิ่งที่ผู้ขอใช้บริการจะได้รับจากเรา

  • ขั้นตอน BI ที่โปร่งใสและเป็นระบบตั้งแต่รับคำขอจนถึงเผยแพร่
  • การช่วยแปลง KPI ให้เป็น logic ข้อมูลที่ชัดเจน
  • การแจ้งข้อจำกัดหรือช่องว่างของข้อมูลอย่างตรงไปตรงมา
  • Dashboard ฉบับร่างให้ตรวจสอบก่อนขึ้น production
  • การอบรมและแนะนำการใช้งานก่อนเปิดใช้งานจริง

เหมาะสำหรับโครงการลักษณะใด

เกณฑ์นี้ช่วยให้ทีมและหน่วยงานประเมินร่วมกันตั้งแต่ต้นว่าโครงการเหมาะกับรูปแบบ BI Dashboard หรือควรใช้บริการข้อมูลรูปแบบอื่น

ลักษณะโครงการที่เข้าเกณฑ์

  • สอดคล้องกับเป้าหมายการบริหารหรือการปรับปรุงการดำเนินงาน
  • ต้องใช้ข้อมูลเพื่อติดตามต่อเนื่อง ไม่ใช่วิเคราะห์เฉพาะกิจครั้งเดียว
  • ใช้ข้อมูลที่อัปเดตเป็นรอบ เช่น รายเดือน รายไตรมาส รายครึ่งปี หรือรายปี
  • ไม่ต้องการข้อมูลแบบ real-time
  • มีเจ้าของ KPI และ Data Champion ที่พร้อมร่วมตรวจสอบข้อมูล

หลักการจัดลำดับความสำคัญ

  • ระดับผลกระทบ: โรงพยาบาล > ฝ่าย/แผนก > ทีม/หน่วยงานย่อย
  • ความถี่ในการใช้งานเพื่อการตัดสินใจเชิงปฏิบัติการ
  • ความพร้อมของ KPI, นิยามข้อมูล และผู้ประสานงานจากหน่วยงาน
  • ความพร้อมของแหล่งข้อมูลและความซับซ้อนของการเตรียมข้อมูล

เนื่องจากกำลังคนด้าน BI มีจำกัด การจัดคิวจะพิจารณาจากผลกระทบ ความพร้อม และประโยชน์ต่อระบบงานโดยรวม หากโครงการไม่เข้าเกณฑ์ ทีมอาจแนะนำบริการข้อมูลแบบ one-time หรือแนวทาง self-service ที่เหมาะสมกว่า

รูปแบบการพัฒนา Dashboard

เพื่อให้หน่วยงานได้รับ Dashboard ที่ตอบโจทย์และยั่งยืน ทีม BI สนับสนุนทั้งรูปแบบ self-service และ centralized development

ทางเลือกที่ 1: User พัฒนาเอง พร้อมทีม BI เป็นที่ปรึกษา

  • รวดเร็วและยืดหยุ่นกว่า
  • หน่วยงานปรับแต่งหน้าจอได้ตรงกับการใช้งานจริง
  • เกิด capability ภายในหน่วยงานในระยะยาว
